# Carry-Gap Project

Regression analysis of the equity-index option **carry gap** (`CG_bp`) for
SPX and RUT, 2016–2025.

## What is the Carry Gap?

The carry gap measures the discrepancy between the discount factor implied
by the options market (via put-call parity) and the OIS risk-free discount
factor at the same maturity:

```
CG_bp = (1/τ) × ln(B_hat / B_OIS) × 10 000
```

A positive carry gap means options imply a higher cost-of-carry than the
risk-free rate — i.e., the options market prices in an **implementation
premium** beyond the frictionless GBM benchmark.

## Quick Start

### Run all experiments end-to-end

```bash
cd /workspace/project
python exp/exp1_carry_gap.py      # ~10 s  – builds cache
python exp/exp2_baseline_reg.py   # ~20 s
python exp/exp3_drift_extension.py
python exp/exp4_horizon_scan.py   # ~2-5 min (horizon grid)
python exp/exp5_loyo_validation.py
python exp/exp6_descriptive.py
```

### Run tests

```bash
cd /workspace/project
pytest tests/ -v
```

### Generate figures directly

```bash
python src/visualization/figure_1_1.py
python src/visualization/daily_fit_plots.py
```

## Model Specifications

| Specification | Regressors |
|---|---|
| **Baseline** | `GBM_1Y, GBM_10Y, BA_over_tau, NFCI` |
| **Extended** | `GBM_1Y, GBM_10Y, GBM_mu_1Y, BA_over_tau, NFCI` |

All regressions use OLS with Newey-West HAC standard errors (`max_lags=21`),
one equation per market (SPX, RUT).

## Key Configuration (`config.py`)

| Parameter | Value | Description |
|---|---|---|
| `START_DATE` | `'2016-01-01'` | Sample start |
| `END_DATE`   | `'2025-10-31'` | Sample end |
| `MAIN_DRIFT_HORIZON` | `504` | Drift proxy horizon in trading days |
| `HAC_MAX_LAGS` | `21` | Newey-West lag truncation |
| `RANDOM_SEED` | `42` | Global RNG seed |

## Notes on Synthetic Data

Real options data from the massive API does not provide the full option
chain required for put-call parity estimation.  All experiments therefore
operate on **synthetic data** generated by `data/options_daily.py` (using
realistic Black-Scholes surfaces with term structure, skew, and bid-ask
spreads) and by the feature modules' direct simulation utilities.  Results
are internally consistent but should not be taken as empirical findings.
